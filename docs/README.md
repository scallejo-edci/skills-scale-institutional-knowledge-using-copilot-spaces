# OctoAcme Project Management Docs

## Summary of Processes
OctoAcme runs cross-functional projects with a customer-first, iterative approach and clear ownership: every project has a named Project Manager and Product Lead. Projects move through five lifecycle stages:

1. **Initiation** - validate the business need with a one-pager, identify stakeholders, and make a go/no-go decision.
2. **Planning** - build a prioritized backlog with acceptance criteria, define the Definition of Done, identify dependencies, and create a release plan.
3. **Execution & Tracking** - daily standups, weekly delivery syncs, small PRs with CI, testing, metrics, and a three-level blocker escalation path.
4. **Release & Deployment** - pre-release requirements, deployment checklist, rollback/incident playbook, and release notes.
5. **Retrospective & Continuous Improvement** - capture learnings after sprints, releases, and incidents, and track action items.

Risk management and stakeholder communication (risk register, status templates, escalation paths) apply throughout the lifecycle. Roles and personas (Project Manager, Product Lead, developers, QA, stakeholders) are described in the roles document.
